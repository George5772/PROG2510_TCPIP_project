# Communication App via TCP/IP

A LAN-based messaging application developed for **PROG2510 – Windows Desktop Programming**.  
This project demonstrates TCP/IP communication using a multi-threaded WPF application and a Windows Service.

---

## Project Overview

Messaging systems are a core part of modern communication.  
This application provides a simple LAN-based messaging solution where clients communicate using TCP/IP through a specified IP address and port.

The project focuses on networking, multithreading, and Windows desktop application development concepts.

---

## Application Design

- Multi-threaded WPF desktop application
- TCP/IP socket-based communication
- Configurable IP address and port
- Backend logic implemented as a Windows Service
- Designed for LAN environments

---

## Tech Stack

- C#
- .NET
- WPF
- Windows Service
- TCP/IP Sockets
